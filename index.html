How to Contribute

It's easy! Follow these simple steps:

⌕

1. Find an Issue

Look for a task labeled good first issue.

→
⑂

2. Fork the Repository

Create your own copy of the project on GitHub.

→
✎

3. Add Your Name

Create your own contributors/username.json file.

→
⑂

4. Commit & Push

Save your changes and push them to your fork.

→
✓

5. Create a Pull Request

Submit your contribution for review.

→
✺

6. See Your Name Live!

Once merged, your name will appear here.
